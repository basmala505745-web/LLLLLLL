# do u love me? 

A cute little animated "do you love me" web page.

## What it does
- An intro screen with a girl character that says hi.
- A "do u love me?" question with a "no" button that runs away when you try to click it.
- A follow-up "so you do love me huh?" screen (same runaway "no" button trick).
- A final reveal screen with a big "MWAAHHH" message and a heartfelt note underneath.

## How to view it
Open `index.html` in any browser — no installation needed.

If this repo has GitHub Pages enabled, you can also open it straight from the link:
`https://<your-username>.github.io/<repo-name>/`

## Tech
Just plain HTML, CSS, and vanilla JavaScript — no frameworks, no build step.
